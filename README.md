# Автосервис - система управления заказами

## Описание

Destop-приложение для автоматизации работы автосервиса.

## Технологии

- **Backend:** Python 3.11, PostgreSQL, psycopg2
- **Frontend:** Tkinter
- **Без ORM** - все SQL-запросы написаны вручную

## Разработка базы данных

Проектирование БД выполнялось поэтапно:

1. Инфологическая модель - выделение сущностей, установка связей между ними, определение бизнес правил
2. Даталогическая модель - разработка схемы таблиц, создание индексов для оптимизации запросов
3. Реализация в PostgreSQL - создание таблиц, реализация объектов БД

## Функциональность приложения

- управление заказами (CRUD, смена статуса)
- складской учёт
- аналитика (вызов хранимых функций и процедуры)
- ведение справочников (клиенты, автомобили, работы, материалы, мастера)
